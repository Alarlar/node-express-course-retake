1. In this lesson, you created a middleware function called asyncWrapper. Why?
Answer: In this lesson, I used an async wrapper because it allows me to write error handling logic once in a middleware and reuse it across controllers.
This way, I avoid repeating try/catch blocks in every method. Write it once and use it for many routes.
